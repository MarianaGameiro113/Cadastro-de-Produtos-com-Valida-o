# 🛒 Cadastro de Produtos

Projeto desenvolvido em **PHP**, **HTML** e **CSS** para realizar o cadastro de produtos em um banco de dados MySQL.

O sistema possui um formulário onde o usuário informa o **nome** e o **preço** do produto. Após o envio, os dados são inseridos na tabela `produtos`.

---

## 📋 Funcionalidades

- Cadastro de produtos
- Campo para nome do produto
- Campo para preço
- Validação dos campos pelo HTML
- Conexão com banco de dados MySQL
- Inserção dos produtos no banco de dados
- Mensagem de sucesso após o cadastro
- Mensagem de erro caso ocorra algum problema
- Interface estilizada com CSS

---

- CSS3
